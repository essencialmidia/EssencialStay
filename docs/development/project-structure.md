# Estrutura para desenvolvimento

- `frontend`: aplicação web React/TypeScript e testes.
- `backend`: serviço HTTP Node e integrações externas.
- `database`: migrations, diagnósticos, seeds reservados e testes SQL.
- `docs`: conhecimento canônico, decisões, histórico e deploy.
- `config`: reservado; não contém configuração funcional atual.
- `essencial-stay-painel-v20`: artefato visual legado separado do frontend atual.
- Arquivos raiz: containers, Nginx, README e instruções de agentes.

Não há workspace npm ou script raiz. Trabalhe dentro do pacote correspondente. Consulte [mapa do projeto](../project-map.md) antes de abrir árvores extensas.
