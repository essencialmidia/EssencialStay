# VISION

**Projeto:** Essencial Stay\
**Versão:** 1.0

## Visão

Ser a principal plataforma brasileira de experiência digital para
hospedagem.

## Missão

Integrar PMS, automação, controle de acesso e serviços em uma única
plataforma aberta.

## Pilares

### Gestão

-   Empresas
-   Propriedades
-   Reservas
-   Usuários

### Experiência do Hóspede

-   Portal Web
-   QR Code
-   Check-in
-   Checkout
-   Concierge

### Inteligência da Propriedade

-   Automação
-   Sensores
-   Energia
-   Fechaduras

## Roadmap

### Fase 1

-   Portal do hóspede
-   Multi-tenant
-   Wubook

### Fase 2

-   Reservas
-   Akubela
-   Tuya

### Fase 3

-   LockProvider
-   White Label

### Fase 4

-   Marketplace
-   IA
-   Analytics

## Integrações Estratégicas

PMS: Wubook, Stays, Cloudbeds

Automação: Akubela, Tuya, Ekaza, Shelly

Controle de acesso: Tuya Smart Lock, Yale, Aqara, Samsung

## Princípios

-   Vendor Agnostic
-   Capability Driven
-   API First
-   Mobile First
-   Security by Design

## Objetivo em 5 anos

Ser referência em hospitalidade inteligente na América Latina.

## Frase Norteadora

Não vendemos automação. Entregamos experiências inteligentes para
hóspedes e eficiência para operadores.
