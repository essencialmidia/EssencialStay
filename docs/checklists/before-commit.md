# Antes de commit

- [ ] Escopo e causa estão claros; não há refatoração incidental.
- [ ] `git status` e diff preservam mudanças alheias.
- [ ] Não há `.env`, token, PIN, chave ou dado pessoal.
- [ ] Código segue o AGENTS local e padrões vizinhos.
- [ ] Teste relacionado, lint e testes do pacote passaram.
- [ ] Build foi executado quando pertinente.
- [ ] Migration/RLS foram revisadas se houver banco.
- [ ] Documentação e links foram atualizados.
- [ ] `git diff --check` passou.
- [ ] Arquivos, riscos, limitações e rollback foram registrados.
