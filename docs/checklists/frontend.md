# Checklist de frontend

- [ ] Fluxo page/context/service/repository foi preservado.
- [ ] Componentes e tokens existentes foram reutilizados.
- [ ] Loading, erro, vazio e sucesso estão cobertos.
- [ ] Submissão/clique repetido é bloqueado.
- [ ] Layout é responsivo e navegável por teclado.
- [ ] Textos são claros em português.
- [ ] Nenhum segredo ou API externa foi levado ao navegador.
- [ ] Contexto visual não foi tratado como autorização.
- [ ] Demo e dado operacional estão claramente separados.
- [ ] Lint, testes e build pertinentes passaram.
