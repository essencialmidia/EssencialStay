# Checklist de release

- [ ] Escopo, versão e responsável foram registrados.
- [ ] Lint, testes e build passaram.
- [ ] Migrations têm ordem, backup e mitigação definidos.
- [ ] Variáveis necessárias foram conferidas sem revelar valores.
- [ ] Imagens Docker e health checks foram validados.
- [ ] Fluxos críticos e isolamento de tenant passaram no smoke test.
- [ ] Integrações mantêm flags/allowlists seguras.
- [ ] Logs e monitoramento estão prontos.
- [ ] Rollback foi ensaiado ou descrito.
- [ ] Documentação e limitações foram publicadas.
